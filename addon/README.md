# PoolSurveylance (Home-Assistant-Add-on)

Pool-Pflege-Assistent: Wasser-Messwerte erfassen und konkrete
Dosiervorschläge auf Basis deiner eigenen Chemikalien erhalten.

Nach der Installation erscheint die App über **Ingress** direkt in der
Home-Assistant-Seitenleiste (Symbol „Pool"). Ein MQTT-Broker ist optional –
ohne MQTT läuft das Add-on ganz normal als Web-App.

Die ausführliche Installations- und Konfigurationsanleitung findest du in
[DOCS.md](DOCS.md).
